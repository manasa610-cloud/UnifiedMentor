HOW TO RUN THE STREAMLIT DASHBOARD
-----------------------------------
1. Make sure both files are in the same folder:
     - afficionado_dashboard.py
     - Afficionado_Coffee_Roasters.xlsx

2. Install requirements (one time):
     pip install streamlit pandas plotly openpyxl

3. Run the app:
     streamlit run afficionado_dashboard.py

4. It will open in your browser at http://localhost:8501
